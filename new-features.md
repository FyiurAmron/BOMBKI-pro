# New features

- Intro cleanup
  - new ASCII banner from `data/banner.aa`
  - no ticks, no keypress wait
  - name before race, validated and stored
  - input auto-uppercased
  - name doubles as save file, load or new game
  - Ctrl+C exits the game
  - name shown on the JA sheet
  - rainbow version line
  - trimmed start sequence
- Removed MODE/UNMODE ceremony
  - all commands run from the normal context
  - ground items listed on room entry
- Debugging improvements
  - all debugging commands are now available in all rooms
  - debug commands and env vars need BOMBKI_DEBUG=2137 in env
- Save functionality improvements
- Polish orthography pass
  - diacritics restored throughout the game texts
  - console output and input switched to UTF-8
  - typed input matches regardless of case and diacritics
  - punctuation and spacing normalized across the texts
- Sentence-case texts
  - game texts read as normal sentences
  - command, item and enemy names stay uppercase
- WYJSCIE always quits
- JSON save system
  - save file is `{charname}.json` and human-readable
  - full bag and monster state preserved, road permit and living door included
- the skills screen shows the real cooking value
- "energia" is now clamped between 0 and max.
- no negative xp
- dying no longer "helps" with first quest
- items dropped on the road by the quest master are visible again
- inventory limit now works correctly
- very failed portal no longer teleports you randomly
  (could teleport you out-of-bounds and brick the game in vanilla)
- better level-up banner
- all rooms show their exit list
- all rooms wired; no longer crashes after going into northern LAS
- handing the diploma over frees a bag slot
- Staruch checks the return scroll before the trade
- command history: up/down arrows scroll previously typed lines
